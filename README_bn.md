# Bill Distribution Apps v2 — নির্দেশিকা

## ব্যবহার (Web ও APK)
1. **💾 ব্যাকআপ** বাটন → "📁 ফোল্ডার নির্বাচন" (Chrome/Edge ডেস্কটপ ও Android Chrome-এ)। অ্যাপ `Bill Distribution Apps` ও ৮টি সাব-ফোল্ডার তৈরি করবে।
2. ফোল্ডার সংযুক্ত থাকলে: প্রতিদিন প্রথমবার অ্যাপ খুললে দৈনিক কপি, প্রতি নতুন মাসে প্রথমবার খুললে মাসিক কপি (সর্বশেষ ৩০ দৈনিক ও ১২ মাসিক রাখা হয়), রিস্টোর/ইমপোর্টের আগে `07 - Recovery`-তে কপি। অ্যাপ বন্ধ থাকলে ব্যাকআপ চলে না।
3. ম্যানুয়াল JSON ব্যাকআপে ঐচ্ছিক পাসওয়ার্ড (AES-256)। **পাসওয়ার্ড হারালে ফাইল খোলা অসম্ভব।**
4. রিস্টোরের আগে প্রিভিউ দেখাবে (কী যোগ হবে, কী বদলাবে, ডুপ্লিকেট)। ফাইল নষ্ট বা বদলানো হলে (SHA-256 না মিললে) রিস্টোর বাতিল হবে।
5. ব্রাউজার রিস্টার্টের পর ফোল্ডারের অনুমতি আবার চাইতে পারে — হোম পেজের "অনুমতি দিন" চাপুন।

## APK তৈরি (কম্পিউটারে Node.js ও Android Studio লাগবে)
```
cd cap
npm install
npx cap add android
npm run sync
npx cap open android      # Android Studio: Build > Build APK(s)
```
`npm run prep` SheetJS-কে `www/`-তে কপি করে, ফলে এক্সেল ইন্টারনেট ছাড়াই চলে।
Web অ্যাপে অফলাইন এক্সেলের জন্য `xlsx.full.min.js` ফাইলটি HTML-এর পাশে রাখুন।

## Android-এ ফাইল কোথায় যায়
Capacitor Filesystem দিয়ে `Documents/Bill Distribution Apps/<সাব-ফোল্ডার>/`-এ। **SAF দিয়ে নিজের পছন্দের ফোল্ডার বাছাই এখনো বাস্তবায়িত হয়নি** (এর জন্য নেটিভ প্লাগইন লাগবে)।

## Play Store প্রস্তুতি
- Google Play Console অ্যাকাউন্ট (এককালীন ফি), নিজস্ব keystore দিয়ে **signed AAB** (Build > Generate Signed Bundle) — keystore ও পাসওয়ার্ড নিরাপদে রাখুন, হারালে আপডেট দেওয়া যাবে না।
- `targetSdkVersion` Play-র বর্তমান শর্ত অনুযায়ী রাখুন (প্রকাশের সময় Play Console-এর নীতি দেখুন)।
- Privacy Policy পাতা (অ্যাপ গ্রাহকের নাম/মোবাইল স্থানীয়ভাবে রাখে, কোথাও পাঠায় না), Data Safety ফর্ম, আইকন, স্ক্রিনশট, বর্ণনা।
- প্রথমে Internal testing track-এ পরীক্ষা করুন।
